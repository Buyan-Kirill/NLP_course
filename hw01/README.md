# PoetryGPT

Небольшая языковая модель для продолжения русских стихов в классической манере.
Обучена со случайной инициализацией: историческая проза → поэзия → продолжение
строки с подсказкой окончания. При инференсе фонетический словарь и ограниченный
поиск помогают выбрать рифмованную вторую строку.

Сохранённая генерация выбранной модели с поиском:

> В саду под вечер свет горит,  
> И в кустах соловей звенит.

68,44 млн параметров · контекст 512 · BPE 8192 · RoPE / RMSNorm / SwiGLU.
Веса другой предобученной языковой модели не использовались.

## Попробовать

После клонирования репозитория перейдите в `hw01/`.
Установите зависимости в **Python 3.12**: `python -m pip install -r requirements.txt`.
Для CPU используйте `requirements-cpu.txt`.
Откройте [inference.ipynb](inference.ipynb), выберите этот Python как ядро и выполните
**Run All**. Первая ячейка загружает проверенные ресурсы; последняя принимает
одну стихотворную строку. Вычисления выполняются локально, на CUDA или CPU.
Установка для Windows, Linux/WSL и macOS — в [инструкции](docs/reproduction.md).

## Состав

[Данные](docs/dataset.md) и [модель](docs/model.md) раскрывают технические детали;
[проверки передачи](docs/validation.md) описывают выполненную валидацию.

`poetrygpt/` — модель и обучение; `reproduction/` — команды и проверяемые рецепты;
`scripts/` — реализации экспериментов, используемые основным маршрутом;
`tests/` — проверки; `audit/` — исходные измерения и генерации, связанные с отчётом.
Датасеты, окружения и обучающие чекпоинты не хранятся в Git.
Готовые веса и фонетические ресурсы загружаются из GitHub Releases с проверкой SHA256.

Основной результат — продолжение строки. Инструкционный SFT исследован отдельно;
его веса не входят в поставляемую модель. Качество зависит от ввода: поиск
повышает частоту рифмы, но не гарантирует осмысленность каждого продолжения.
