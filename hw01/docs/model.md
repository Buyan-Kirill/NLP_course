# Модель и обучение

Decoder-only Transformer: **68 440 576 параметров**, 20 слоёв, ширина 512,
8 голов, SwiGLU FFN 1408, RoPE, RMSNorm, общий вес embedding и выходной проекции.
Контекст 512, byte-level BPE 8192, dropout 0,1. Реализация —
[poetrygpt/model.py](../poetrygpt/model.py).

| Этап выбранной цепочки | Данные и бюджет | Обучение |
|---|---|---|
| Претрейн D | 630 193 557 токенов, три прохода прозы | Случайная инициализация; Muon + AdamW; batch 16 384 токена; прогрев 10 млн токенов, cosine 3e-4 → 3e-5 за 1,05 млрд; на остановке LR 1,25e-4 |
| Завершение LR50 | Ещё 50 млн токенов прозы | Сохранённые оптимизаторы и sampler; LR того же расписания ×0,5 |
| Поэзия | 1 615 779 токенов, первый проход | Новые оптимизаторы; LR 3e-5 → 3e-6 по cosine за два прохода; batch 16 384 токена |
| Поэзия, второй проход | Ещё 1 615 779 токенов | То же расписание и состояния; batch уменьшен до 4096 токенов |
| Подсказка окончания | 400 тыс. токенов | 50% обычной поэзии / 50% условного продолжения; новые оптимизаторы, LR 5e-5 → 5e-6 на 1,6 млн токенов; остановка на 400 тыс.; batch 1024 токена |

Бюджет и batch учитывают **токены, включённые в loss**, а не число строк
или длину с padding. Метаданные не поступают в модель. CE сравнивает
`logits[:, :-1]` с `labels[:, 1:]`; prefix и padding имеют label `-100`.
Окна не объединяют целевые фрагменты разных произведений; между эпохами
меняются границы окон и порядок. Потери в батче нормируются по числу целевых токенов.

Muon применяется к двумерным матрицам скрытых слоёв: momentum 0,95,
5 Newton–Schulz итераций, `match_rms_adamw`. Embedding/общая выходная матрица
и одномерные параметры обучаются AdamW, betas=(0,9; 0,95), eps=1e-8.
Weight decay 0,1 для матриц, 0 для одномерных параметров AdamW;
clip нормы градиента 1, BF16. Группы параметров проверяются на полное
покрытие без повторного обновления общего embedding.

Инструкционный SFT и поздний SFT продолжений — отдельные сравнительные ветви;
они не входят в выбранные веса. Финальный метод добавляет к модели
[поиск рифмы](inference22.md). Результаты и исходные кривые — в
[отчёте](report/index.html).
