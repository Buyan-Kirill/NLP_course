# Выбор рецепта

Полные кривые, сопоставимые выборки и исходные генерации находятся в
[HTML-отчёте](report/index.html). Здесь приведены решения, определяющие основной маршрут.

| Сравнение | Наблюдение | Решение |
|---|---|---|
| Размер, глубина и оптимизатор | Сравнивались архитектуры и AdamW/Muon; низкий validation loss сам по себе не обеспечивал связную генерацию | Выбрана глубокая модель D, 68,44 млн параметров, Muon + AdamW |
| Дополнительные 50 млн токенов | Validation NLL: CE 2,7598; LR ×0,5 — 2,7356; шум 5% — 2,7801; смесь данных — 2,7592 на общей панели | Завершение претрейна с LR ×0,5; дальнейшие эпохи не добавлялись автоматически |
| Поэтическая адаптация | Первый проход и уменьшение batch сравнивались с сохранением общего расписания и оценкой смысла | Два прохода; во втором batch 4096 токенов |
| Конечные слова и план | Усиление loss окончаний, явная подсказка и отбор вариантов давали разные результаты на train и validation | В выбранных весах — 400 тыс. токенов смеси с задачей «контекст → окончание → строка» |
| Инструкционный и поздний SFT | Исследованы вопросы, просьбы, диалог и продолжение строки | Эти ветви оставлены сравнительными; в выбранные веса не включены |
| Поиск рифмы | На заключительных шести ситуациях: рифма 5/6, смысл вместе с рифмой 3/6 у двух независимых агентов | Финальная демонстрация — продолжение строки с фонетическим ограничением |

Оценка генераций: пять критериев по 0–2 — соответствие вводу, развитие мысли,
логика, естественность речи и стиль. Сумма 0–10; рифма оценивается отдельно.
Шесть ситуаций — небольшая качественная проверка, не широкий бенчмарк.
NLL/PPL и Top-1 считаются по токенам на фиксированных выборках; Distinct-2
и повторы четырёхсловий — по свободным продолжениям. Их определения и
состав каждой панели показаны рядом с результатами в отчёте.

Исправление неоднозначных ударений после заключительной оценки меняет
фонетический выбор при инференсе, сохраняя веса и численный поиск.
Примеры в отчёте — сохранённые ответы модели с указанием этапа и источника.
